# Maynard의 구간별 소수 런과 일반 Q1 연결 검토

기준 소스: `cd7bbe3`. 이 문서는 문헌에서 읽은 사실, 그로부터의 자연어 추론,
후속 Lean 계약을 구분한다. 기존 정리의 가정이나 장부의 상태를 올리지 않는다.
소수 런의 존재를 해석적 정수론으로 증명하는 부분은 Lean 밖에 둔다.

## 1. 원문과 매개변수

- J. Maynard, *Dense clusters of primes in subsets*,
  [arXiv:1405.2593v2](https://arxiv.org/pdf/1405.2593v2), Theorem 3.3와 증명의 식 (6.26).
- 출판 정보: Compositio Mathematica 152 (2016), 1517–1554,
  [DOI](https://doi.org/10.1112/S0010437X16007296). 기존 대조 보고서에서 출판본 식 (6.24)로 대응시켰다.
  아래에서 직접 재확인한 식 번호는 arXiv v2의 것이다.

**원문 확인:** Theorem 3.3은 `q ≤ (log x)^(1−ε)`, `r ≤ c_ε log log x`,
`gcd(a,q)=1`을 요구한다. 여기서 `r`은 논문의 문자열 매개변수 `m`을 바꿔 쓴 것이며,
`p_n,...,p_(n+r)`은 `r+1`개다. `q`가 소수라는 조건은 없다.
증명 (6.26)은 `[x,2x]`의 정수 v 가운데 `[qv,qv+η log x]` 안에 같은 류 a의
전역 연속 소수들을 포함하는 v의 개수에 하한을 준다. 적용할 때는 선형식
`L_i(v)=qv+a+qb_i`의 상수항 a도 고려해, 여유 있게 `[qv,qv+a+η log x]`를 쓴다.
고정된 a와 `η≤1/2`에 대해 이 창은 충분히 큰 x에서 `[qv,qv+log x]`에 들어간다.
구간 안의 다른 수를 합성수로 만드는 (6.20)의 양수 조건이 전역 연속성을 보장한다.

**매개변수 수정:** `ε=1`이면 q의 범위가 `q≤1`이므로 q≥3에 적용할 수 없다.
`ε=1/2`로 고정하면, 고정된 q와 r에 대한 두 범위 조건은 충분히 큰 모든 x에서 성립한다.
원하는 길이가 K≥2이면 보수적으로 `r=K`를 택해 확보된 런의 처음 K개를 취한다.
(6.26)의 `≫ log k` 표기만으로 개수를 단정하지 않고, (6.20)의 양수성이
적어도 r개(수식의 엄격한 양수성으로는 r+1개)의 소수를 확보한다는 점을 함께 쓴다.
`k`, `η`, 존재 문턱은 q와 K를 정한 뒤 고정한다. K가 q에 의존해도 q를 먼저 고정하므로 문제가 없다.

## 2. 올림과 자릿수 구간: 직접 추론

구간 하단 U에 대해 `Y=ceil(U/q)`로 두고 원문의 x 자리에 Y를 넣는다.
`v∈[Y,2Y]`이면

```text
U ≤ qv ≤ 2qY ≤ 2U+2q.
```

상수항 a와 `η log Y`의 합을 `log Y`로 흡수하도록 Y의 문턱도 키운다.
따라서 확보된 소수들은 `[U,2U+2q+log Y]`에 있다. q가 고정이면
`log ceil(U/q)=o(U)`이므로, 충분히 큰 모든 U에서 `2q+log Y≤U`이고
이 구간은 `[U,3U]`에 포함된다. 여기서 문턱은 q와 K에 의존해도 된다.

기존 `2U+q` 상계의 반례는 `q=7`, `U=1,000,000`, `Y=142,858`이다.
`2qY=2,000,012 > 2U+q=2,000,007`이지만 수정 상계 `2U+2q=2,000,014`는 만족한다.
이는 작은 정수 산술로 경계 오류를 확인한 것이며 소수 분포에 관한 계산 증거가 아니다.

이제 `U=10^(d−1)`로 놓으면 `[U,3U]⊂[U,10U)`다. 따라서 충분히 큰 **모든** d에서
같은 d자리이고 모두 `1 mod q`인 길이 K의 연속 소수 런을 얻는다 (`a=1`).
단순히 그런 런이 무한히 많다는 진술만으로는 아래의 자릿수 선택을 대신할 수 없다.

## 3. 일반 유한 소수 집합 회피: 직접 추론

유한 소수 집합 S와 인덱스 하한 N을 고정한다.

1. `T=S\{2,5}`로 둔다. T가 비어 있으면 n≥4에서 `gcd(W_n,10)=1`인 기존 정리로 끝난다.
2. T가 비어 있지 않으면 `M=∏_(q∈T) q≥3`, `gcd(M,10)=1`이다. Euler 정리로
   `L=φ(M)>0`, `10^L≡1 mod M`이다. `d=L*t`를 충분히 크게 택한다.
3. 2절을 `q=M`, `K=M`에 적용한다. 구간 하단이 `p_(max(N,3)+1)`보다 커지도록 d를 키우면,
   시작 인덱스 n이 `max(N,3)`보다 크고 다음 M개의 소수
   `p_(n+1),...,p_(n+M)`가 모두 d자리이며 `1 mod M`이다.
4. 이어 붙이기 점화식에서 각 단계는 mod M로 1을 더하는 전이가 된다. 따라서
   `W_(n+j)≡W_n+j mod M` (`0≤j≤M`). `0≤j<M`의 M개 값은 모든 나머지를 순회하므로
   어떤 j에서는 `W_(n+j)≡1 mod M`이다. 초기 나머지를 미리 알 필요는 없다.
5. T의 각 소수는 M을 나누므로 그 W항을 나눌 수 없다. n+j≥4이므로 2와 5도 나누지 못한다.
   또한 n+j>N이다. 따라서 S의 모든 소수를 동시에 피한다.

이 논증은 WB3를 가정하지 않는다. `3∈S`에서도 적용 가능한 후보이며,
기존 `not_windowBlocks3_of_three`와 모순되지 않는다.
S를 고정한 다음에야 M과 문턱을 선택한다. S 전체에 공통인 자릿수나 문턱을 주장하지 않는다.

## 4. 후속 Lean 계약

다음은 **진술 계약**이다. 이 문서의 코드 블록에는 증명을 넣지 않는다.
기존 `IntervalTriplesAll`은 소수 모듈러스의 세 개 런만 다루므로 아래 가정을 대신할 수 없다.

```lean
def IntervalOneRuns (m : ℕ) : Prop :=
  ∃ x₀ : ℕ, ∀ x : ℕ, x₀ ≤ x →
    ∃ n : ℕ, ∀ j : ℕ, j < m →
      x ≤ Nat.nth Nat.Prime (n + j) ∧
      Nat.nth Nat.Prime (n + j) ≤ 3 * x ∧
      Nat.nth Nat.Prime (n + j) ≡ 1 [MOD m]

def IntervalOneRunsAll : Prop :=
  ∀ m : ℕ, 2 ≤ m → m.Coprime 10 → IntervalOneRuns m

theorem avoid_finset_of_intervalOneRunsAll
    (h : IntervalOneRunsAll) (S : Finset ℕ)
    (hS : ∀ q ∈ S, q.Prime) (N : ℕ) :
    ∃ n : ℕ, N < n ∧ ∀ q ∈ S, ¬ q ∣ W n
```

문헌에서 `IntervalOneRunsAll`을 얻는 부분은 이름 붙인 명시적 가정으로 Lean 밖에 둔다.
Lean에서 검증할 부분은 Euler에 의한 자릿수 선택, 블록 안의 합동 전이, 모든 나머지의 순회,
유한 집합과 2·5의 처리다. 새 가정을 `axiom`, 인스턴스, 구조체 필드에 숨기지 않고,
Audit와 blueprint의 definition 노드에 등록한다.

## 5. 증거의 경계와 완료 조건

- 자연어 논증은 원문의 가정과 식에 대조하고, 별도의 읽기 전용 검토를 받는다.
- 2026-11-11 독립 읽기 전용 검토에서는 반례나 차단할 문제를 찾지 못했다. 그 검토에서 요구한
  런 개수의 근거, 상수항 a의 흡수, `Nat.nth Nat.Prime N` 기준 첨자를 이 문서에 반영했다.
  검토는 Maynard의 체 논증 자체를 재증명하거나 새로운 Lean 계약을 컴파일한 것은 아니다.
- 후속 Lean 구현은 `lake build`, 모든 선언의 공리 감사, blueprint 대응, checkdecls와 PR CI로 별도 검증한다.
- 일반 Q1을 얻어도 남은 항이 두 큰 소수의 곱인 가능성은 배제되지 않는다. 최종 `SWInfinitude`는 별도 문제다.
- 이 조사는 새롭거나 알려지지 않은 결과라는 주장이 아니다. 프로젝트 안의 미연결 부분을 검토하는 것이다.
