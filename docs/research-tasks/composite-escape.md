# 일반 수열의 유한 소수 회피와 소수성 사이의 간극 검증

종류: 형식화 (`enhancement`, `lemma-hunt`). 일반 Q1을 최종 소수성으로 잘못 승격하는 추론을 검증할 기준을 만든다.
연속 소수 두 개의 곱 수열은 모든 항이 합성수여도 모든 유한 소수 집합을 결국 피한다.
이는 일반 수열에 관한 논리적 간극의 예이며 SW 수열에 대한 반증이 아니다.

## 고정 계약

`namespace SW` 안에 아래 선언을 정확히 추가한다. 기존 W나 SWInfinitude는 바꾸지 않는다.

```lean
noncomputable def primePairProduct (n : ℕ) : ℕ :=
  Nat.nth Nat.Prime n * Nat.nth Nat.Prime (n + 1)

theorem primePairProduct_strictMono : StrictMono primePairProduct

theorem primePairProduct_not_prime (n : ℕ) : ¬ (primePairProduct n).Prime

theorem primePairProduct_avoid_finset
    (S : Finset ℕ) (hS : ∀ q ∈ S, q.Prime) (N : ℕ) :
    ∃ n : ℕ, N < n ∧ ∀ q ∈ S, ¬ q ∣ primePairProduct n
```

네 선언은 무조건적이다. `IntervalOneRunsAll`이나 새 해석적 가정을 받지 않는다.
0-based `Nat.nth Nat.Prime n = p_(n+1)` 첨자와 빈 S를 포함한 양화사를 유지한다.
