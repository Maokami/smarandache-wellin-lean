# 연구 계획

최신 현황과 다음 과제는 9절(2026-11-13)을 기준으로 읽는다. 8절은 이전 전략의 역사 기록이다.

## 1. 현실적 기대치

메르센 수, 페르마 수, n! + 1 처럼 지수적으로 커지는 결정적 수열에서 소수가 무한히 많다는 증명은 어느 경우에도
없다. Smarandache–Wellin 수열도 같은 부류다. 따라서 완전 증명을 목표로 두되, 진전의 기준은 "쉬운 보조정리의
개수" 가 아니라 **"핵심 미해결 단계가 줄어드는가"** 로 잡는다.

산출물의 우선순위:

1. 정의·점화식·합동식 구조의 Lean 형식화 (`SmarandacheWellin/`).
2. 서로 다른 3~5개 증명 전략의 구조와, 각 전략의 **핵심 미해결 보조명제의 정확한 서술**.
3. 조건부 정리: 명시된 분포 가정 아래서 무한성 또는 더 약한 결론.
4. 실패한 전략, 반례, 논리적 간극의 기록 (`lemma-ledger.md`).

## 2. 휴리스틱

Dₙ = Σₖ≤ₙ d(pₖ) 라 하면 log Wₙ = Dₙ log 10 + O(1) 이고, d(pₖ) = log pₖ / log 10 + O(1) 이므로

```
log Wₙ = Σₖ≤ₙ log pₖ + O(n) ~ pₙ ~ n log n .
```

크기 Wₙ 의 무작위 정수가 소수일 확률을 1 / log Wₙ 으로 보면 소수 항의 기대 개수는
Σ 1/(n log n) ~ log log N 으로 발산하지만 매우 느리다. n ≥ 4 부터 끝자리가 1, 3, 7, 9 이므로 2, 5 에 대한
보정 인자가 붙는다 (`coprime_ten_of_three_le`). 이것은 **기대일 뿐 증명이 아니다**: 확률 합의 발산만으로
사건이 무한히 일어난다고 결론 내릴 수 없고, Wₙ 은 결정적 수열이다.

**보정 결과** (`scripts/sw_heuristic.py`, c = 2.5): 4 ≤ n ≤ 1429 에서 기대 2.98, 관측 6. 1430 ≤ n ≤ 4·10⁶ 에서
기대 1.49, 관측 0 (P₀ ≈ 0.23). 모형과 관측은 양립한다. 다음 항은 n ~ 10¹⁰–10¹² 근처에서야 기대값 1 이 쌓이므로,
**새 항을 계산으로 찾는 전략은 버린다.** 계산은 분포 가정의 점검에만 쓴다.

## 3. 양화사에 주의

```
(A)  ∀ B, ∃^∞ n, Wₙ 에 B 이하의 소인수가 없다
(B)  ∃^∞ n, Wₙ 은 소수
```

(A) 를 완전히 증명해도 (B) 는 남는다. 소수 판정에 필요한 경계는 고정된 B 가 아니라 항마다 커지는 √Wₙ 이고,
두 큰 소수의 곱도 모든 고정된 작은 소수를 피한다. (A) 는 체 방법의 1단계일 뿐이다.

## 4. 전략 비교

| 전략 | 핵심 아이디어 | 먼저 확인할 것 | 반드시 제출할 결과 |
| --- | --- | --- | --- |
| 합동식·동역학 | rₙ₊₁ ≡ aₙ rₙ + pₙ₊₁ (mod m), aₙ = 10^{d(pₙ₊₁)}. gcd(m,10)=1 이면 각 단계는 Z/m 의 순열 | 궤도가 섞이는가, 특정 상태에 갇히는가. 입력 pₙ mod m 의 균등분포가 누적 상태의 균등분포를 함의하지 않음 | Wₙ mod m 에 관한 정확한 보조명제와 필요한 가정 |
| 해석적 정수론·체 | 작은 소인수를 제거하고 남는 항의 개수를 추정 | 나머지 분포를 얼마나 큰 모듈러스까지 통제해야 하는가. 패리티 장벽 | 필요한 분포 추정식, 모듈러스 범위, 그 추정으로 얻는 결론 |
| 확률 모형·상관관계 | Σ 1/log Wₙ 의 발산을 정교화 | 독립성 가정 없이 무엇을 말할 수 있는가 | 계산 결과와 비교할 분포, 증명에 필요한 상관관계 추정 |
| 자리수·구조적 변환 | 문제를 합동식·소인수 지수·자리수·계수 문제로 바꾼다 (Erdős #728 의 교훈) | 자리수 분포가 지정된 접두사의 소수성에 연결되는가 | 원래 문제와의 동치 또는 한 방향 함의 |
| 장애물·반증 탐색 | 항들을 합성수로 강제하는 피복이나 규칙을 찾는다 | 무한성을 방해하는 숨은 구조가 있는가 | 제안된 보조명제의 반례, 또는 전략이 부족한 이유 |
| 문헌 연결 | RH·GRH, Dirichlet, Bateman–Horn 등 | 그 정리의 정확한 가정이 우리 수열에서 충족되는가 | "이 추정식을 X 에서 얻을 수 있고, 그것으로 이 보조명제가 따라온다" 형태의 서술 |

"RH 를 가정하고 시작하자" 는 금지. 대신 **"우리 증명에 어떤 분포 추정이 필요한가? 그 추정은 RH·GRH 에서
얻을 수 있는 종류인가?"** 를 묻는다. 현재 RH·GRH 가 이 추측을 함의한다는 연결은 확보되지 않았다.

## 5. 가장 약한 고리 규칙

유망한 전략마다 즉시 세 부분으로 나누고, 비어 있는 부분을 적는다.

1. 어떤 m 에 대해 어떤 의미의 분포인가?
2. 그 분포로 작은 소수를 피하는 항을 얼마나 확보하는가?
3. 남은 항이 큰 소수들의 곱일 가능성을 어떻게 배제하는가?

3 이 비어 있으면 1, 2 를 아무리 형식화해도 원래 증명은 완성되지 않는다.

## 6. 피해야 할 지름길

- 유클리드 논법: 소수들의 곱 + 1 은 새 소인수를 주지만 그것이 Wₙ 꼴이라는 보장이 없다.
- Dirichlet 정리: 고정된 등차수열의 소수 무한성은, 붙일 숫자가 다음 소수로 고정된 이 문제에 바로 적용되지 않는다.
- 자리수의 무작위성: 숫자 패턴이 잘 분포한다는 것과 지정된 접두사들이 소수라는 것은 별개다.
- 계산 사례의 증가: 새 항은 증거이지 증명이 아니다. n ≤ 4·10⁶ 까지 이미 탐색되었고, 보정 모형은 다음 항을
  n ~ 10¹⁰–10¹² 에서 기대하므로 새 항 발견은 사실상 불가능하다.
- Bateman–Horn: 고정된 다항식의 소수 값에 관한 추측이라 이어 붙이기 수열에 그대로 적용되지 않는다.

## 7. 작업 방식

- 의존 구조와 Lean 대응은 블루프린트 (`blueprint/src/content.tex`) 에 둔다. 새 정리는 블루프린트 노드, `Audit.lean`,
  장부를 함께 갱신하고 `scripts/blueprint.sh --lean` 으로 대응을 확인한다.
- 전략마다 목표 명제 하나를 `lemma-ledger.md` 에 등록한다. 명제는 변수 범위와 양화사를 포함해 Lean 으로 서술
  가능한 형태로 적는다.
- 증명되지 않은 명제는 Lean 파일에 `sorry` 로 두지 않는다. 장부에만 둔다.
- 작은 계산 실험(`scripts/`)으로 명백히 틀린 분포 가정을 먼저 제거한다. 실험은 증명을 대신하지 않는다.
- 살아남은 구조적 보조정리부터 Lean 으로 검증한다. 타당성이 불분명한 해석적 가설의 대규모 형식화는 미룬다.
- Lean 실패를 "명제가 거짓" 으로 읽지 않고, 자연어로 그럴듯하다는 이유로 "문법 문제일 뿐" 이라고도 단정하지
  않는다. 실패를 (i) 수학적 전략의 오류, (ii) 보조명제가 너무 커서 탐색 실패, 로 구분해 기록한다.
- 최종 검증: 목표 명제와 정의의 일치, `#print axioms`, 툴체인·Mathlib 버전 고정 재빌드, 계산을 썼다면 그 검증
  방식, 사람이 읽는 증명과 Lean 정리의 대응 설명.

## 8. 이전 가장 약한 고리 (2026-11-05, 2차, 역사 기록)

Q1 (유한 소수 집합 회피) 을 밀어 본 결과:

- |S| = 1 은 무조건 증명했다 (`exists_not_dvd`). 한 소수는 연속한 세 항 중 하나를 놓친다.
- |S| = 2 는 **소수만의 가정**으로 환원했다. 두 소수 q, r 가 모든 항을 덮으려면 번갈아 나눠야 하고, 그러면 q 는
  n 또는 n+1 에서 두 칸 간격으로 나누어 블록 Bₙ 또는 Bₙ₊₁ 을 나눈다 (`block_dvd_or_succ_of_cover`). 그래서
  "q ∤ Bₙ ∧ q ∤ Bₙ₊₁ 인 n 이 무한" (HB(q)) 이면 어떤 r 에 대해서도 끝난다 (`avoid_two_of_block_succ`).
  - q = 3: 10 ≡ 1 (mod 3) 이라 자릿수가 사라지고, HB(3) 은 "연속 소수 세 개가 mod 3 에서 같은 류" (H3) 와
    같다. H3 ⇒ 3 이 든 모든 쌍의 Q1 (`avoid_three_of_triples`).
  - 일반 q: 같은 류의 쌍에서 q ∣ Bₙ 은 q ∣ 10^d + 1 (d = 자릿수) 과 같고, 어떤 소수도 10^d + 1 과 10^{d+1} + 1
    을 둘 다 못 나눈다. 그래서 같은 류의 세 쌍이 d 자리와 d+1 자리 안에 각각 있으면 (Hd(q)) 끝난다
    (`avoid_two_of_digit_triples`). Hd(q) 는 "큰 모든 x 에 대해 [x, 2x] 에 같은 류의 연속 소수 세 개" 에서 따른다.
- H3, Hd(q) 는 W 와 무관한 **연속 소수의 나머지류 정리**다. 문헌 확인 결과 (`docs/literature/`):
  H3 는 Banks–Freiberg–Turnage-Butterbaugh (2015) Corollary 3 이 그대로 준다. Hd(q) 는 구간 판 가정 IT(q)
  ("큰 x 마다 [x, 3x] 에 같은 류의 연속 소수 세 개") 에서 Lean 으로 유도했고 (`Interval.lean`), IT(q) 는
  Maynard (2016) Theorem 3.3 증명의 식 (6.24) 에서 따른다. 단 "[x, 2x]" 형태를 정리문으로 적은 논문은 없다.
  Maynard 체에 기반한 깊은 결과이고 Mathlib 에 없으므로, IT(q) 와 H3 는 Lean 밖의 가정으로 둔다.
- 계산 (n < 2·10⁶): H3 비율 0.18, HB(q) 는 모든 q ≤ 23 에서 0.18 이상. q = 19, 23 의 같은 류 세 쌍은 8 자리에서야
  처음 보인다 (연속 소수가 같은 류를 피하는 편향). 즉 Hd(q) 의 근거는 계산이 아니라 정리다.
- |S| ≥ 3 은 덮는 패턴이 주기적이지 않아 같은 환원이 바로 되지 않는다. 3 이 든 집합은 특히, mod 3 나머지가
  {1, 2} 에서만 움직이므로 "길이 ≤ 3 의 모든 창이 0 이 아닌 합" 이 불가능하다. 비둘기집 한 번으로는 안 된다.

당시 **가장 약한 고리는 Shiu 형 정리를 Lean 밖의 가정으로 받아들일지, 아니면 |S| ≥ 3 과 (A) 로 가는 길을 찾을지**였다.
다음 선택지:

1. (완료) 문헌으로 H3, IT(q) 를 확정하고 장부에 `자연어 증명 (문헌)` 으로 올렸다. 남은 흠은 IT(q) 의 근거가
   정리문이 아니라 증명 내부 식이라는 점이며, Shiu 정리 자체의 형식화는 Maynard 체 전체가 필요해 범위 밖이다.
2. |S| ≥ 3: 덮는 패턴을 분류하거나, 밀도 논법 (각 {n : q ∣ Wₙ} 의 상밀도가 1/q 에 가깝다는 Q2 형 가정) 으로
   바꾼다. 이때 mod 3 은 소수 합 Σ pₖ mod 3 의 분포 문제가 된다.
3. 다른 전략 (체, 동역학) 에서도 같은 "연속 소수 분포" 가정이 필요한지 본다. 그렇다면 가정 하나로 여러 전략을
   묶을 수 있다.

  (`SW.avoid_finset_of_intervalOneRunsAll`, 기준 main `30482b5`). CI·공리 감사·Blueprint·독립 검토가 통과했다.

- 작은 소인수를 피하는 항이 무한히 많다는 결론에서 소수 항의 무한성으로 가는 연결은 여전히 미해결이다.
  무조건 Q1, Q2, Q4와 최종 추측의 상태를 올리지 않는다.
- `3`이 포함된 WB3 창 조건은 PR #11에서 반증했다. 그 전략을 다시 사냥 과제로 만들지 않는다.

연구 제안은 하루 한 번, 형식화는 기존 하루 한 건, 열린 연구 PR은 최대 두 건이다.

같은 실패 과제는 main 변경만으로 재시도하지 않는다. 새 전략·관련 의존성 변경을 본문에 기록하거나 수동 재시도를 지정한다.
