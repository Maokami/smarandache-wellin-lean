# 연속 소수 가정 H3, HB(q), Hd(q) 의 계산 점검 (2026-11-05)

명령: python3 -I scripts/sw_triples.py --n 2000000 --primes 3 7 11 13 17 19 23
범위: 3 ≤ n < 2·10⁶ (p_{n+1} ≤ 32452843). 증명이 아니다.

해석:
- (1) HB(q) = "q ∤ B_n ∧ q ∤ B_{n+1}" 의 비율. Avoid.lean 의 avoid_two_of_block_succ 의 가정이며, q 하나에
  대해서만 성립하면 임의의 r 에 대해 Q1({q, r}) 이 따른다. 모든 q 에서 0.18 이상이다.
  q = 3 은 독립 예측 (2/3)² = 0.44 보다 훨씬 낮다 (0.18): HB(3) 은 "연속 소수 세 개가 mod 3 에서 같은 류"
  (H3) 와 동치인데, 연속 소수는 같은 류를 피하는 편향이 있기 때문이다 (같은 류 쌍 비율 0.435, 독립 0.5).
  n = 2·10⁵ 에서는 0.1687, 2·10⁶ 에서는 0.1797 로 독립 예측 쪽으로 천천히 움직인다 (편향은 x → ∞ 에서 사라짐).
- 10^d ≡ −1 (mod q) 인 자릿수 d 에서는 B_n ≡ p_{n+2} − p_{n+1} (mod q), 즉 블록 조건이 "소수 간격이 q 의
  배수가 아니다" 로 바뀐다. 간격은 작은 값에 몰려 있어 q ∣ B_n 이 1/q 보다 드물다. q = 17 (d = 8 에서 10⁸ ≡ −1)
  의 비율 0.94 가 독립 예측 0.89 보다 높은 이유. 같은 이유로 q = 11 (홀수 d 에서 10^d ≡ −1) 은 n = 2·10⁵
  (d = 7 지배) 에서 0.89, 2·10⁶ (d = 8 지배) 에서 0.84.
- (3) Hd(q) 는 "같은 류의 세 쌍이 모든 큰 자릿수 d 안에 있다" 는 가정이다. q = 3, 7 은 d ≥ 4 에서 매번 관측되지만
  q = 17 은 d = 7 에서 11 개, q = 19, 23 은 d = 8 에서야 각각 13, 3 개가 처음 보인다 (d = 8 에서 17 은 51 개). 큰 q 에서는 연속 소수가 같은 류를 강하게
  피하므로 (Lemke Oliver–Soundararajan) 이 범위의 계산은 Hd(q) 를 약하게만 지지한다. Hd(q) 의 근거는
  Shiu (2000) / Maynard (2016) 류의 정리이지 계산이 아니다.
- "q ∣ 10^d + 1 인 d" 열은 같은 류 쌍 (p_{n+1}, p_{n+2}) 에서 q ∣ B_n 이 되는 자릿수다. q = 3 에는 없고
  (not_three_dvd_pow_add_one), 그 밖의 q 에서는 d 가 ord_q(10)/2 의 홀수 배일 때다. 두 자릿수 d, d+1 을 함께
  쓰면 어느 q 도 둘 다 나눌 수 없다 (not_dvd_pow_add_one_both).
